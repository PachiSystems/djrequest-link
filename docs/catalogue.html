Catalogue sync

Choose playlists from your Engine DJ library and upload just those tracks as the catalogue guests can request from.

Your Engine DJ database is opened read-only: it's never modified, and it's never uploaded. Only a list of the selected tracks (title, artist, album, genre, BPM, key and similar details) is sent. File paths on your computer are not included.

Find your Engine DJ database

SystemLocation
macOS~/Music/Engine Library/Database2/m.db
Windows%USERPROFILE%\Music\Engine Library\Database2\m.db
USB driveEngine Library/Database2/m.db on the drive

Close Engine DJ first. The tool reads a snapshot of the database without locking it, so changes Engine DJ hasn't saved yet won't be included. It warns you if it spots unsaved changes.

Sync

  1. List your playlists 
    $ djrequest-link catalogue list-playlists --db "/path/to/m.db"
  2. Preview the sync 
    $ djrequest-link catalogue sync --db "/path/to/m.db" --playlist "House/Deep" --playlist "Top 100" --dry-run

    Shows how many tracks would be uploaded. Needs no API key and sends nothing.

  3. Sync for real 
    $ djrequest-link catalogue sync --db "/path/to/m.db" --playlist "House/Deep" --playlist "Top 100"

A sync replaces your whole catalogue with exactly the tracks in the playlists you name. Pass every playlist you want requestable in one command.

Choosing playlists

  • --playlist accepts a full path (House/Deep), a title if it's unique, or the numeric id from list-playlists.
  • Repeat it for several playlists. A track in more than one playlist is only counted once.

Re-syncing

Run the same command again after changing your playlists. If nothing changed, the upload is skipped. The tool remembers the last sync in djrequest-link.manifest.json in the folder you run it from (it never contains your API key). Add --force to upload anyway.

Other commands

  • catalogue export --db … --playlist … --out tracks.json writes the track list to a file instead of uploading it — useful to see exactly what would be sent.
  • catalogue inspect --db … prints read-only diagnostics about the database layout. Include its output if you report a problem reading your library.

Troubleshooting

“Unsupported schema”

The file isn't an Engine DJ Database2/m.db, or it's from a version the tool doesn't recognise yet. Please open an issue with the output of catalogue inspect (it contains table and column names and a few sample values — remove anything you'd rather not share).

“Playlist … is ambiguous”

Two playlists share that title. Use the full path or the numeric id instead.

The sync is rejected with a track limit

Your plan allows fewer tracks than you selected. Choose fewer or smaller playlists.
