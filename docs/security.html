Security & privacy

djrequest-link holds an API key that can change your DJRequest.me account, and it reads your music library and listens on your network. Here's exactly how it handles each.

Your API key

  • Stored only in your OS keychain (auth set-key): macOS Keychain, Windows Credential Manager, or the Linux Secret Service. The tool never writes it to a file or a log.
  • Never on the command line of a helper program. When talking to the keychain, the key is passed privately (on standard input), so other users on the computer can't see it in the process list.
  • Only sent over HTTPS, only to the API address you configured. The tool refuses plain http:// except to localhost, and never follows a redirect with your key attached.
  • Not sent to file storage. Catalogue uploads go to a short-lived signed URL; the key isn't included.

If you think your key has leaked, regenerate it on the Developer page of your DJRequest.me admin — the old key stops working immediately — then run djrequest-link auth set-key again.

Your Engine DJ library

  • Opened read-only, in a mode that doesn't lock it or create any files next to it.
  • Never uploaded. Only a list of the tracks in the playlists you choose is sent — title, artist, album, genre, BPM, key, length, year, label and similar. File paths from your computer are not included.
  • The sync state file (djrequest-link.manifest.json) records the last upload's fingerprint and settings. It never contains your API key.

Your network

now-playing watch and now-playing devices use StagelinQ, the protocol Denon / Engine DJ gear uses on your local network:

  • It listens for, and sends, device announcements on UDP port 51337.
  • It connects out to your players over TCP. It never opens a port that other devices can connect to.
  • It ignores announcements from outside your laptop's own local network(s).
  • Everything received from the network is treated as untrusted: sizes are checked before anything is read, only the values the tool asked for are used, and titles/artists are cleaned and length-limited before being sent to DJRequest.me.
  • It reads only play state, fader position, and track title/artist from your gear.

No tracking

There is no telemetry, analytics or crash reporting. The only place djrequest-link sends anything is the DJRequest.me API address you use. Error messages are printed on your screen and go nowhere else.

No dependencies

The tool uses only Node.js itself — no third-party packages — so installing it doesn't pull in anyone else's code. The source is public on GitHub, and every change is checked in CI, including a guard that blocks committed databases, library exports, keys and hidden characters.

Reporting a vulnerability

Please don't open a public issue. Report it privately using Report a vulnerability on the repository's Security tab.
