djrequest-link

A small command-line tool that runs on your laptop and connects your DJ setup to DJRequest.me.

Now Playing

Follows your Denon DJ / Engine DJ gear over StagelinQ and shows the track you're playing on your venue's live display — automatically, as you mix.

Set up Now Playing →

Catalogue sync

Reads your Engine DJ library (read-only), and uploads the playlists you choose as the tracks guests can request.

Sync your catalogue →

What you need

  • Node.js 24 or newer on the laptop you DJ from — download it from nodejs.org (the “LTS” version is fine if it's 24+). Standalone installers that don't need Node are planned.
  • A DJRequest.me plan that includes the Developer API. Now Playing also needs the Now Playing feature on your plan.
  • For Now Playing: Engine DJ hardware on the same network as your laptop.

Install

Open a terminal (Terminal on macOS, PowerShell on Windows) and run:

$ npm install -g github:PachiSystems/djrequest-link

Check it worked:

$ djrequest-link --version

To update later, run the install command again. To remove it: npm uninstall -g djrequest-link.

djrequest-link has no dependencies — the install downloads only this tool's own code, which you can read on GitHub.

Set up

  1. Save your API key

    Find your key on the Developer page of your DJRequest.me admin, then run:

    $ djrequest-link auth set-key

    Paste the key when asked (it isn't shown as you type). The tool checks it works, then stores it in your computer's keychain — macOS Keychain, Windows Credential Manager, or the Linux Secret Service. It's never written to a file.

  2. Find your venue id 
    $ djrequest-link venues list

    Copy the id of the venue you're playing at. You'll pass it as --venue <id>.

  3. Pick what to do next

    Show what you're playing on the live display, or sync your Engine DJ playlists as your catalogue.

Commands at a glance

CommandWhat it does
auth set-keyStore your API key in the OS keychain.
auth statusShow which key is in use and where it came from.
venues listList your venues and their ids.
now-playing watchFollow your gear and keep Now Playing up to date.
now-playing devicesList StagelinQ devices on the network.
now-playing set / clearSet or clear Now Playing by hand.
catalogue list-playlistsList the playlists in your Engine DJ library.
catalogue syncUpload chosen playlists as your requestable catalogue.

Every command has built-in help, e.g. djrequest-link now-playing --help. The command reference lists every option.

Running from source

If you'd rather not install globally, clone the repository and run it directly — there's nothing to build:

$ git clone https://github.com/PachiSystems/djrequest-link.git
$ cd djrequest-link
$ node bin/djrequest-link.js --help
