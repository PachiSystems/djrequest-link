Command reference

Commands are grouped: djrequest-link <group> <command> [options]. Add --help to any group for the same information in your terminal.

Global options & environment

Option / variableMeaning
--api-url <url>DJRequest.me address. Default https://www.djrequest.me. Must be https://; plain http:// is allowed only for localhost.
--api-key <key>API key for this one command. Prefer auth set-key — command-line flags end up in your shell history.
DJREQUEST_API_KEYAPI key, used instead of the keychain.
DJREQUEST_API_URLDefault for --api-url.
DJREQUEST_VENUE_IDDefault for --venue.
DJREQUEST_NO_KEYCHAIN=1Never read the OS keychain.
DJREQUEST_DEBUG=1Show stack traces for unexpected errors (they can include file paths from your machine).
-h, --help / -v, --versionHelp / version.

The API key is looked up in this order: --api-key, then DJREQUEST_API_KEY, then the keychain entry saved for the API URL in use.

auth

CommandOptionsWhat it does
auth set-key--no-verifyPrompts for your key (hidden), or reads it from stdin when piped. Checks it against the API unless --no-verify, then saves it in the OS keychain for the API URL.
auth status--checkShows the API URL and the last four characters of the key in use, and where it came from. --check also tests it.
auth remove-keyDeletes the saved key for the API URL.

now-playing

CommandWhat it does
now-playing watchFollows StagelinQ gear and keeps Now Playing up to date until you press Ctrl+C. Refuses to start if the venue's live display is off.
now-playing devicesLists StagelinQ devices found on the network.
now-playing showPrints the current Now Playing.
now-playing setSets Now Playing by hand: --title (required), --artist.
now-playing clearClears Now Playing.
OptionCommandsMeaning
--venue <id>watch, show, set, clearVenue to update. Not needed with --dry-run.
--dry-runwatchPrint decisions only; send nothing. Needs no API key.
--mode <m>watchauto (default), master, or deck:1–deck:4. See how it decides.
--min-play <s>watchSeconds a track must be heard before it counts (auto mode). 0–600, default 10.
--fader-threshold <n>watchFader position below which a deck is silent. 0–1, default 0.05.
--idle-clear <min>watchClear after this many minutes with nothing playing. Default 3.
--interface <ip>watch, devicesUse only the network adapter with this IPv4 address.
--verbosewatchPrint device events and every playing deck's state.
--seconds <n>devicesHow long to listen. Default 5.

catalogue

CommandWhat it does
catalogue list-playlistsLists playlists with ids and track counts.
catalogue syncUploads the selected playlists as your catalogue, replacing it. Skipped when unchanged since the last sync.
catalogue exportWrites the normalized track list to a file.
catalogue inspectRead-only database diagnostics.
OptionCommandsMeaning
--db <path>allPath to the Engine DJ m.db.
--playlist <sel>sync, exportFull path, unique title, or numeric id. Repeatable.
--dry-runsyncShow counts, size and hash; no network, no key.
--forcesyncUpload even if unchanged.
--manifest <file>syncChange-detection file. Default ./djrequest-link.manifest.json.
--out <file>exportOutput file.
--jsonlist-playlists, inspectMachine-readable output.
--samples <n>inspectSample values per metadata type (default 3).
