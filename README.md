# djrequest-link

Local companion tool for [DJRequest.me](https://djrequest.me). Runs on your own
laptop.

Work in progress. Planned features:

- **Catalogue sync:** read your Engine DJ library read-only, pick playlists, and
  upload just those tracks as your requestable catalogue.
- **Now Playing:** read the current track from Denon / Engine DJ gear over
  StagelinQ and show it on your venue's live display.
